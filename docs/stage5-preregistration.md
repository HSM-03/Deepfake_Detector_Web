# 5단계 사전 등록 — P_rppg 분류기와 경계 구간 판정

이 문서는 **결과를 보기 전에** 정한 규칙이다. 시험 쌍의 특징을 뽑거나 보기 전에 커밋하고, 이후 바꾸지 않는다.
바꿔야 하면 이 문서를 고치지 않고 아래 "변경 기록"에 이유와 함께 덧붙인다(결과를 본 뒤의 변경임을 밝힌다).

- 작성: 2026-10-25. 근거: `docs/backend-plan.md` 5단계 결정 사항·세부 계획.
- FaceForensics++는 rPPG 특징 분석과 P_rppg 분류기 학습에만 쓴다. 메인 모델은 FF++에 돌리지 않는다.

## 1. 데이터

- **조작 방식: Deepfakes 하나**(4-1과 같음). **압축 단계: raw(c0)**.
- **한 쌍** = original 영상 a + 그 영상에 다른 얼굴을 합성한 Deepfakes a_b.
- **나누기 단위 = 묶음 (a, b)**: FF++ 쌍 목록(`filelist.json`)의 한 줄 [a, b]에서 가짜 a_b·b_a가 나오고, a_b에는 b의 얼굴이 들어 있다.
  그래서 한 묶음의 두 쌍 (a, a_b)·(b, b_a)는 항상 같은 쪽에 둔다. **번호 a·b는 학습과 시험에 동시에 나오지 않는다.**
- **4-1의 25쌍**(`backend/out/stage5/batch_00_old25.json`의 목록, 아래 4절)은 **학습에만** 넣는다. 이 25쌍의 번호가 든 묶음은 새로 고르지 않는다.
- **새 200쌍(묶음 100개)**: 4-1 번호가 들지 않은 묶음을 `filelist.json` 순서대로 놓고 난수 시드 0으로 섞어 앞에서 100개를 고른다.
  섞인 순서의 앞 50묶음 = **학습**(100쌍), 다음 50묶음 = **시험**(100쌍). 결과 목록은 `docs/stage5/ffpp_split.json`(4절).
- **제외 규칙** (학습·시험 같게, 특징 값을 보기 전에 정함):
  - 쌍의 두 영상 중 하나라도 열 수 없거나, **길이가 10초 미만**(서비스가 분석하지 않는 길이)이거나, **rPPG 얼굴 추적률이 70% 미만**이면 그 쌍을 뺀다.
  - 4-1 25쌍 중 10초 미만 2쌍(192_134, 241_210)도 이 규칙으로 빠진다.
  - 뺀 쌍은 개수와 이유를 결과에 적는다. 빠진 시험 쌍은 다른 쌍으로 채우지 않는다.

## 2. P_rppg 분류기 (5-2·5-3)

- **입력: 특징 6개 고정** — `hr_in_range`, `snr`, `spectral_entropy`, `roi_bpm_std`, `phase_consistency`, `window_bpm_var`.
  서비스와 같은 함수(`analysis/rppg_features.compute`, 앞 60초 제한)로 뽑는다. SQI는 입력으로 쓰지 않는다.
- **전처리**: 값이 없는 특징(NaN)은 학습 쌍의 중앙값으로 채우고, 학습 쌍 기준으로 표준화한다(채우기·표준화 모두 학습 쌍에서만 맞춘다).
- **모델: 로지스틱 회귀 하나로 고정.** 라벨 가짜 = 1, 진짜 = 0. **P_rppg = 가짜일 확률**(1에 가까울수록 가짜).
- **설정 고르기**: 정규화 강도 C ∈ {0.01, 0.03, 0.1, 0.3, 1, 3, 10}를 **학습 쌍 안에서만** 5겹 교차검증(묶음 단위로 나눔, 시드 0)으로 고른다. 기준은 교차검증 AUC 평균.
  - SVM(RBF)은 **학습 쌍 교차검증에서 비교로만** 본다. 결과와 상관없이 최종 모델은 로지스틱 회귀다.
- **최종 모델**: 고른 C로 학습 쌍 전체(4-1 25쌍 포함, 제외 규칙 적용 후)에 맞춘다.
- **시험 쌍 평가는 최종 모델로 딱 한 번만 한다.** 그 뒤 설정·특징·제외 규칙을 바꿔 다시 평가하지 않는다.

## 3. 성공 기준과 실패 시 대안

- **성공 기준: 시험 쌍에서 P_rppg의 AUC 95% 신뢰구간 하한 > 0.5.**
  - AUC = 가짜 영상의 P_rppg가 진짜 영상보다 클 확률. 신뢰구간 = 쌍 단위 부트스트랩 2,000회(같은 쌍의 진짜·가짜를 함께 뽑음), 시드 0. 4-1과 같은 계산.
  - 참고로 함께 적는다(판정에는 쓰지 않음): AUC 값, 4-1 주 특징 하나의 AUC(0.63)와의 비교, 학습 쌍 교차검증 AUC.
- **성공하면**: 분류기를 서비스에 연결한다(5-3). `USE_DUMMY_P_RPPG`를 끈다.
- **실패하면 (대안)**: **P_rppg는 판정에 쓰지 않고, SQI가 높고 심박이 정상 범위인데 메인 모델이 가짜로 확신하면 판단 보류로 보낸다.**
  - "SQI가 높다", "가짜로 확신" 기준은 5-5에서 정한다(예시: SQI ≥ 0.7(양호 등급), P_model ≥ 0.6(가짜 구간)). 심박 정상 범위는 특징 `hr_in_range`(45~180BPM).
  - 이 경우 화면의 P_rppg 자리에는 "분류기 기준 미달로 판정에 쓰지 않음"을 표시한다.
- **참고 확인 (성공 기준과 별개)**: 직접 찍은 원본 8편(`backend/out/` 06~13번, 깃 제외)의 P_rppg가 진짜 쪽(0.5 미만)으로 나오는지 본다. 결과만 적고 기준에 반영하지 않는다.

## 5. 경계 구간 판정 (5-5, 검증 세트를 보기 전에 기록)

- 대상: 종합 점수 S가 0.4~0.6이고 두 축이 상충하지 않는 영상(|P_model − P_rppg| < 상충 임계).
- **후보 3개**: (가) 모두 **진짜**로 판정 (나) 모두 **가짜**로 판정 (다) 모두 **판단 보류**.
- **고르는 기준**: Celeb-DF 검증 세트(평가 세트 518개 제외, 인물 단위)에서
  1. **확신 오류율이 가장 낮은 후보**를 고른다. 확신 오류율 = 진짜/가짜로 판정했는데 틀린 영상 수 ÷ 전체 영상 수.
  2. 단, **판단 보류 비율 상한**을 넘는 후보는 고르지 않는다. 판단 보류 비율 = (상충 보류 + 경계 보류) ÷ 전체. **상한 20%** (2026-10-25 확정, 검증 세트 결과를 보기 전).
  3. 확신 오류율이 같으면 보류가 적은 후보를 고른다.

## 6. 그 밖의 정해 둔 것

- α·임계값: Celeb-DF 검증 세트에서는 "융합해도 메인 모델 단독보다 나빠지지 않는다"만 확인한다(α 효과가 거의 없을 것으로 예상).
- 특징 기준값(5-4): 학습 쌍의 FF++ 진짜 영상 + UBFC 원본만 쓴다. 시험 쌍 영상은 넣지 않는다.
- 팀원 영상: 5-6에서 값이 모두 확정된 뒤 한 번만 돌려 "메인 모델 단독 vs 융합"을 본다. α·임계값·SQI 기준을 정하는 데 쓰지 않는다.
